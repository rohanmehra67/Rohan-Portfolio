# Images required

Put these files in this folder.

## Required

1. `profile.webp`
   - Your main portrait/photo for the hero section.
   - Prefer a transparent PNG/WebP or a portrait with a clean background.

2. `project-1.webp`
   - Screenshot/cover image of your strongest project.

3. `project-2.webp`
   - Screenshot/cover image of project 2.

4. `project-3.webp`
   - Screenshot/cover image of project 3.

5. `project-4.webp`
   - Screenshot/cover image of project 4.

6. `project-5.webp`
   - Screenshot/cover image of project 5.

## Optional

- `favicon.png`
- `og-image.webp` (1200x630 social preview image)

You can also use `.jpg`/`.png`, but then update the paths in `src/data.js`.

The current UI intentionally uses local assets rather than hotlinking random images.
