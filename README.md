# Rohan's Portfolio

A full-stack personal portfolio built with React and Node.js, featuring a responsive UI, smooth animations, and a functional contact form.

**Tech Stack:** React, Vite, Tailwind CSS, Framer Motion, Node.js, Express, MongoDB, Mongoose, Nodemailer, Lucide React.

**Features:**
- Responsive design and smooth animations
- Contact form with validation
- MongoDB message storage
- Email notifications via SMTP
- REST API and health check endpoint

**Architecture:** React frontend with an Express backend, MongoDB database, and secure server-side email integration.
